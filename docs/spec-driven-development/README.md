# Spec-Driven Development

Este diretorio separa o conhecimento do projeto em specs pequenas e reutilizaveis.

## Objetivo

- Explicitar o produto.
- Reduzir ambiguidade antes de implementar.
- Dar contexto suficiente para um LLM trabalhar sem adivinhar.
